# 🌿 AgroCircular: Desperdício Zero

Plataforma digital desenvolvida para o **Concurso Agrinho 2026**, sob o tema **"Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente"**.

Este projeto foi idealizado e programado por um aluno do **1º ano do Ensino Médio**, com o objetivo de aproximar a tecnologia do produtor rural, promovendo as práticas de **Economia Circular** no campo.

---

## 🎯 Objetivo do Projeto

O **AgroCircular** demonstra de forma prática que dentro de uma propriedade rural "nada se perde, tudo se transforma". O site funciona como um guia informativo e uma ferramenta de tomada de decisão para o agricultor, provando que a sustentabilidade ambiental caminha lado a lado com a rentabilidade econômica.

---

## 💻 Estrutura do Site (3 Páginas/Seções Integradas)

O site foi construído em uma estrutura de página única dinâmica (*Single Page Application*), dividida em três grandes seções para facilitar a navegação do produtor:

1. **O Concurso Agrinho:** Explicação sobre a importância do tema de 2026 e a relevância de discutir o equilíbrio ecológico. Apresenta conceitos visuais de fluxos de resíduos (como a transformação de dejetos suínos em biogás e biofertilizantes).
2. **Simulador NPK (Ferramenta Interativa):** Uma calculadora inteligente onde o produtor insere a quantidade de resíduos orgânicos gerados na fazenda. O sistema estima a quantidade de nutrientes (Nitrogênio, Fósforo e Potássio) que seriam gerados via compostagem e calcula a economia financeira em reais ao deixar de comprar adubo químico.
3. **Sobre Mim:** Seção dedicada à apresentação do autor do projeto, destacando a visão de um estudante do Ensino Médio sobre o futuro do agronegócio sustentável.

---

## 🛠️ Tecnologias Utilizadas

Para manter o site leve, acessível para o meio rural (onde a conexão de internet pode ser limitada) e de fácil manutenção, foram utilizadas as tecnologias web fundamentais:

* **HTML5:** Estruturação semântica de todo o conteúdo e formulários.
* **CSS3:** Design responsivo, moderno e focado em uma paleta de cores que remete à sustentabilidade (tons de verde folha e terra).
* **JavaScript (Vanilla):** Lógica de programação para processar os dados da calculadora NPK em tempo real, sem necessidade de recarregar a página.

---

## 📊 Como Funciona o Cálculo do Simulador?

A lógica inserida no script faz uma estimativa baseada em médias de rendimento de compostagem orgânica:
* **Aproveitamento de Nutrientes:** Considera que cerca de 5% do peso bruto do resíduo se converte em NPK biodisponível após o tratamento correto.
* **Fator de Economia:** Utiliza uma estimativa de mercado onde cada quilo de resíduo reciclado poupa aproximadamente R$ 0,45 que seriam gastos em fertilizantes minerais comerciais.

---

## 🚀 Como Executar o Projeto Localmente

1. Faça o download ou clone este repositório.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estejam na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web (Google Chrome, Edge, Firefox, etc.).
